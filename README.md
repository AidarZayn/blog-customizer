# Проектная работа: Вёрстка проекта

Проектная работа выполнена с целью закрепления материала по основам React, а именно закрепление материала с синтаксисом React и TSX. Также работа с хуками, пропсами.

[Макет проекта](https://www.figma.com/file/FEeiiGLOsE7ktXbPpBxYoD/Custom-dropdown?type=design&node-id=0%3A1&mode=design&t=eXRJnWC6Xsuw0qR4-1)

## Команды для запуска проекта

Установка пакетов проекта:

```
npm install
```

Запуск проекта:

```
npm run start
```

Для запуска Storybook:

```
npm run storybook
```

Для запуска линтера для стилей:

```
npm run stylelint
```

Для запуска линтера:

```
npm run lint
```

Для запуска форматтера:

```
npm run format
```
